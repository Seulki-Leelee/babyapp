# 👶 영유아 라이프사이클 CRM & D2C 커머스 연계 MVP 모바일 웹앱

> **유아동 D2C 자사몰 마케터 관점에서 기획 및 개발된 모바일 웹 솔루션**  
> 사용자의 일상 육아 데이터(수유, 기저귀, 수면, 체온)를 실시간 추적하고, 재고 소진 시점 감지 및 AI 건강 분석을 통해 자사몰 커머스와 자연스럽게 연결하는 CRM 라이프사이클 MVP입니다.

---

## 🌟 프로젝트 핵심 가치 및 마케팅 전략 (CRM Points)

1. **사용 빈도(Frequency) 기반 UX 설계**
   - 매일 수십 번 발생하는 **[수유 / 기저귀 / 수면]** 기록과 **시간순 육아 타임라인**을 홈 메인 화면 전면에 배치하여 사용자 락인(Lock-in) 유도.
   - 체온/열 케어 및 재고 관리 등 저빈도 요소는 온디맨드 팝업 & 알림 배너로 처리하여 시각적 획기적 간소화.

2. **D2C 자사몰 연계 재고 인벤토리 & 원클릭 리필 CRM**
   - 기저귀 18매 / 분유 2캔 소진 임박 시 스마트 **재고 알림 배너** 자동 발동.
   - `[통합 인벤토리 모달]`에서 실시간 수량 게이지 확인, 10%/15% 전용 할인 쿠폰 발급, 정품 바코드 스캔 60매 리필, 1초 원클릭 재주문 연결.

3. **AI 딥러닝 건강 분석 기반 맞춤 큐레이션**
   - 대변/피부 사진 스캔 시 소아과 데이터 기반 황금변 장 건강도(95점) 분석 ➔ 덴마크 100억 생유산균 1+1 기획전 1:1 맞춤 연결.
   - 체온 38.0°C 이상 입력 시 **고열 경고 뱃지 & 해열제 4시간 교차투여 타이머** 발동 ➔ 케어&샵 탭 최상단 `[열감 진정 쿨링패치 & 수딩밤]` 긴급 큐레이션 카드 노출.

4. **공동육아 바통터치 & 포토 육아일기 리텐션**
   - 엄마 ↔ 아빠 원터치 육아 교대 상태 공유 위젯.
   - 아기 성장 순간(D+120일 뒤집기 성공 등) 폴라로이드 앨범 렌더링 ➔ 아크릴 포토액자 굿즈 커머스 연동.

## 🛠️ 기술 스택 (Tech Stack)

- **Frontend**: React (v18), TypeScript, Vite
- **Styling**: Tailwind CSS (웜베이지/코랄 파스텔 테마), Custom Micro-Animations
- **Icons & Visuals**: Lucide Icons, Canvas Confetti
- **Viewport**: Mobile-first Viewport (Max width 430px centered)

---

## 🚀 시작하기 (Quick Start)

### 1. 패키지 설치
```bash
npm install
```

### 2. 개발 서버 실행
```bash
npm run dev
```
접속 주소: `http://localhost:5173/`

### 3. 프로덕션 빌드
```bash
npm run build
```
